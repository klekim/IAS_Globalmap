# IAS Global Network Map

An interactive visualization of the Institute for Advanced Study (IAS) global network, displaying the worldwide distribution of IAS institutes and highlighting NetIAS member institutions.

## 📋 Project Overview

This project generates an interactive global map displaying all IAS institutes worldwide. The map differentiates between NetIAS member institutes and other affiliated institutions using color-coded markers:

- 🔴 **Red Stars**: NetIAS member institutes
- 🔵 **Blue Stars**: Other IAS institutes

## 📁 Project Structure

```
IAS_Map/
├── README.md                  # Project documentation
├── IASmap_render.py          # Python script to generate the map
├── IAS_Worldwide.csv         # Dataset containing institute information
└── IAS_Global_Map.html       # Generated interactive map (output)
```

## 📊 Files Description

- **IASmap_render.py**: Main Python script that processes the CSV data and generates an interactive Folium map with statistics and markers
- **IAS_Worldwide.csv**: Contains institute data including:
  - Institute names and locations
  - Latitude and Longitude coordinates
  - NetIAS membership status
  - Other relevant institute information
- **IAS_Global_Map.html**: Interactive HTML map (generated by the script, can be opened in any web browser)

## 🚀 Getting Started

### Prerequisites

- Python 3.7+
- Internet connection (for map tiles and CDN resources)

### Installation

1. Clone or download this project
2. Install required Python packages:

```bash
pip install folium pandas
```

### Usage

Run the script to generate the map:

```bash
python IASmap_render.py
```

This will:
1. Read the institute data from `IAS_Worldwide.csv`
2. Process and validate coordinates
3. Generate statistics about NetIAS membership
4. Create an interactive map with markers
5. Save the output as `IAS_Global_Map.html`

### Viewing the Map

Open `IAS_Global_Map.html` in your web browser to interact with the map:
- **Zoom**: Scroll to zoom in/out
- **Pan**: Click and drag to move around
- **Click Markers**: View institute information
- **Legend**: Located in the bottom-left showing institute counts and percentages

## 📈 Features

- Interactive world map visualization using Folium and Leaflet
- Color-coded markers distinguishing NetIAS members from other institutes
- Statistics summary showing:
  - Total number of institutes
  - NetIAS membership count and percentage
  - Geographic distribution
- Responsive design that works in modern web browsers
- Legend with real-time statistics

## 📝 Data Format

The `IAS_Worldwide.csv` should contain columns including:
- Institute name/identifier
- Latitude
- Longitude
- NetIAS membership status (yes/no or true/false)
- Other relevant institute information
